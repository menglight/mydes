# Decision Assistant

This project is a decision assistant application that helps users make informed decisions by crawling relevant information from the web, processing it, and presenting it in a user-friendly interface.

## Modules

- **Backend:** Handles data processing, API, and database interactions. (Django)
- **Frontend:** Provides the user interface for interacting with the application. (React)
- **Crawlers:** Responsible for fetching data from various web sources. (Scrapy)
